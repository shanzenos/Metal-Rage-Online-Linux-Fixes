# Metal-Rage-Online-Linux-Fixes
Repository for linux compatibility fixes for the "Metal Rage Online" game client

**This patch currently ONLY works with ProtonGE 8-3
This patch modifies the D3D9DVR.dll & Znetwork.dll libraries to circumvent the client's protection systems and run the game on Linux devices under Proton.

Client & Installer files avaliable [Here](https://archive.org/download/metal-rage-online-client/MetalRage%20Online/).

Documentation for the fixes is in the Wiki [Here](https://github.com/shanzenos/Metal-Rage-Online-Linux-Fixes/wiki)
